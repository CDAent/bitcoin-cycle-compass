# API Register
## Bitcoin Cycle Compass — Version 8.7 · Sprint 0

This register documents every external API endpoint consumed by Bitcoin Cycle Compass, plus the internal static data endpoint served by GitHub Pages. All external API calls originate from Python scripts running in GitHub Actions. A subset of APIs are also called directly from the browser as a fallback when `live.json` is unavailable.

---

## 1. Internal Data Endpoint

### live.json

| Field | Value |
|---|---|
| **Method** | `GET` |
| **Route** | `data/live.json` (relative; served by GitHub Pages) |
| **Full URL** | `https://<github-pages-domain>/data/live.json` |
| **Purpose** | Primary data payload. Contains all computed scores, prices, history, news, ETF data, and build metadata. Generated by `update_data.py` and served as a static file. |
| **Authentication** | None (public static file) |
| **Cache Strategy** | Network-first via service worker (`cache: 'no-store'` + timestamp query string `?v=<Date.now()>`) |
| **Response Format** | `application/json` — see `Data_Flow.md` section 4 for full schema |
| **Used By** | `refreshLiveData()` in `index.html` |
| **Cadence** | Regenerated on each GitHub Actions run (triggered by push to `main` or `workflow_dispatch`) |

## 13. API Error Handling

### Python (update_data.py)

- All external calls are wrapped in `safe(fn, default)` — any exception returns the default value
- Missing or failed feeds result in `None` or neutral score values, not hard failures
- ETF flow errors are captured in `errors[]` array within the response
- DB failures log warnings and rollback — they do not abort the JSON write

### JavaScript (index.html)

- `refreshLiveData()` catches all errors and falls back to `browserFallback()`
- `browserFallback()` uses `Promise.allSettled()` — partial failures are tolerated
- Missing data fields produce `'Unavailable'` labels rather than blank or errored UI
- `ensureEtfIndication()` synthesises a market proxy if the live ETF proxy is absent
- `fetchBrowserNews()` tries 3 sources in sequence; if all fail, hardcoded search links are used
- `escapeHtml()` and `safeUrl()` protect all externally sourced strings before DOM insertion
